# Panghu 网页项目内容概览

版本：0.0.2-5.18

## 项目定位

**批量图片生成工具**，帮助亚马逊卖家：

1. 从商品图 + 卖点文字中提取结构化商品信息（AI 分析）
2. 生成主图 / A+ 的英文绘图提示词（模板 + AI）
3. 调用图像生成 API 批量出图，并管理历史结果

应用主体在浏览器运行，**无业务后端**，纯前端应用。

## 技术栈与文件结构

| 文件 | 规模 | 职责 |
|------|------|------|
| `index.html` | ~500 行 | 页面结构、表格、各类 Modal |
| `script.js` | ~6300 行 | 全部业务逻辑 |
| `style.css` | ~3100 行 | UI 样式 |

**技术特点：** 纯 HTML/CSS/JS，无框架、无构建；设置存 `localStorage`（键 `aiSettings`）；图片以 base64 方式展示。

## 双模块架构

- **智能表格**：完整功能，逻辑封装在 `SmartTableModule` 命名空间。
- **Amazon Visual Agent**：预留模块，后续扩展。
- **水印**：为表格中已生成的结果图与历史图批量叠加水印。
- **设置（J）**：API 与提示词模板。

## 智能表格：列与行工作流

| 列 | 字段 | 功能 |
|----|------|------|
| A | 序号 | 行号、多选、分组、删除 |
| B | 商品图 | 上传/多图、预览、图库展开 |
| C | 卖点 | 文本输入 +「提取」 |
| D | 提取结果 | 展示/点击编辑、AI 辅助分析 |
| E | 提示词 | 亚马逊模式（主图/A+）或自由模式 |
| F | 尺寸 | 模型选择 + 比例预设 |
| G | 结果图片 | 当前生成图 |
| H | 历史图片 | 缩略图、展开、批量下载 |
| I | 操作 | 测试生成 / 生成 |

典型流程：上传商品图与卖点 → 提取 → 主图/A+ 提示词 → 选择 prompt 生成 → 结果与历史管理。

## AI 与 API 集成

| 能力 | 默认端点/模型 | 用途 |
|------|----------------|------|
| 图像识别 | ai.comfly.org + gpt-5.2 | 图+文卖点提取 |
| 文本分析 | api.deepseek.com + deepseek-chat | 纯文本提取 |
| 图片生成 | gpt-image-2 | 默认出图 |
| Gemini | gemini-3.1-flash-image-preview | 备选 |

**提示词模式：**

- **亚马逊模式**：主图 12 张（1:1）、A+ 8 张（21:9）；占位符 `{product_name}`、`{extract_result}`。
- **自由模式**：手写 prompt 直接出图。

## 批量与协作功能

- 多行选择、批量提取、批量删除
- 批量导入图片
- 行分组：拖拽、Shift 连选 + Ctrl+G、右键菜单、展开/收起（状态可持久化）
- 复制行到底部、测试生成、历史图下载

## 如何运行

1. 用浏览器直接打开 `index.html`
2. 按 **J** 配置 API Key 与模板

## 数据持久化

- **API 与模板**：`localStorage` → `aiSettings`
- **表格行数据**：`localStorage` → `smartTableData`（文本、提示词、图片等，受浏览器容量限制）
- **分组**：`localStorage` → `smartTableGroups`
