# 智能表格 - 使用说明

详细架构与功能说明见 [项目概览.md](项目概览.md)。

## 快速开始

直接用浏览器打开 `index.html` 即可使用。也可以使用任意静态文件服务器（VS Code Live Server、`npx serve` 等）。

## 功能说明

### 1. AI设置（按J键打开）
- 图像识别API：配置图片分析的API
- 文本分析API：配置纯文本分析的API
- 提示词模板：自定义AI分析的提示词

### 2. 卖点提取
- 上传商品图片
- 输入卖点文字
- 点击"提取"按钮

### 3. 批量提取
- 勾选多个商品序号
- 点击底部"批量提取"按钮

### 4. 结果编辑
- 点击提取结果可查看完整内容
- 支持手动编辑
- 支持AI修改

### 5. 水印
- 顶部水印按钮导入水印图
- 「一键添加水印」为所有已生成的结果图与历史图叠加水印

### 6. 数据保存
- 表格内容与分组在刷新后会从浏览器本地存储恢复（图片较多时可能受容量限制）

## 在其他电脑使用

1. 将整个文件夹复制到U盘或云盘
2. 在目标电脑上粘贴
3. 用浏览器打开 `index.html` 即可

Q: 刷新后部分图片未恢复？
A: 浏览器 localStorage 有大小上限，可减少每行历史图数量或定期导出重要图片
