# 智能表格 - 使用说明

## 快速开始

### Windows系统（推荐）
1. 双击 `start.bat` 文件
2. 浏览器会自动打开网页
3. 开始使用！

### Mac/Linux系统
1. 打开终端，进入项目目录
2. 运行：`python3 start.py`

## 配置说明

编辑 `config.json` 文件可以修改配置：
- port: 服务器端口（默认8000）
- host: 监听地址（127.0.0.1=仅本机）
- auto_open_browser: 是否自动打开浏览器

## 功能说明

### 1. AI设置（按J键打开）
- 图像识别API：配置图片分析的API
- 文本分析API：配置纯文本分析的API
- 提示词模板：自定义AI分析的提示词

### 2. 卖点提取
- 上传商品图片
- 输入卖点文字
- 点击"提取"按钮

### 3. 批量提取
- 勾选多个商品序号
- 点击底部"批量提取"按钮

### 4. 结果编辑
- 点击提取结果可查看完整内容
- 支持手动编辑
- 支持AI修改

## 在其他电脑使用

1. 将整个文件夹复制到U盘或云盘
2. 在目标电脑上粘贴
3. 双击 `start.bat` 启动

## 常见问题

Q: 提示"端口已被占用"？
A: 修改 config.json 中的 port 为其他端口

Q: 浏览器没有自动打开？
A: 手动输入：http://localhost:8000/index.html

Q: 提示"未检测到Python"？
A: 请先安装Python：https://www.python.org/downloads/
