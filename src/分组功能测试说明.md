# 分组功能测试说明

## 功能已实现

✅ 所有分组功能已经实现完成，包括：
1. 拖拽分组
2. Shift+点击+Ctrl+G快捷键分组
3. 右键菜单取消分组
4. 展开/收起组
5. 从组中移除单个行

## 测试步骤

### 1. 启动应用
直接用浏览器打开 `index.html`

### 2. 测试拖拽分组
- 鼠标按住序号1的单元格
- 拖动到序号3的单元格上
- 松开鼠标
- 预期：序号1显示为 `1 (2)`，序号3被隐藏，出现"展开组"按钮

### 3. 测试展开/收起组
- 点击"展开组"按钮
- 预期：序号3显示，按钮变为"收起组"

### 4. 测试Shift+点击+Ctrl+G分组
- 点击序号2
- 按住Shift，点击序号5
- 按Ctrl+G
- 预期：序号2、3、4、5被分为一组

### 5. 测试右键菜单 - 取消分组
- 右键点击组长行的序号
- 选择"取消分组"
- 预期：组被解散，所有行显示

### 6. 测试右键菜单 - 从组中移除
- 展开一个组
- 右键点击组员行的序号
- 选择"从组中移除"
- 预期：该行从组中移除

## 已知限制

1. 分组状态会保存到 `localStorage`（键 `smartTableGroups`），刷新后可恢复
2. 删除行时会自动从分组中移除或解散小组
